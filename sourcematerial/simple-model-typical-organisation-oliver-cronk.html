This is very much an initial draft, and is in response to the fact that I couldn't find a standard model out there [if someone has found one please share it!]. The closest I've been pointed to so far is this from Bizzdesign. But that is a bit too Enterprise Architecture Centric for my liking.

The point of this model (click the pic above to view a larger version of my initial doodle) is to try and carve out primary responsibilities, interface / communication points and concerns in a typical strategy - architecture - transformation / programme & operations type organisation.

UPDATED PICTURE following feedback (again click to view a full version)

I think this by and large works for most organisations I've worked for. Its obviously an initial draft and is not perfect. Didn't want to spend too much time on it as I expect someone will tell me it has been done already! But if it hasn't and others think it has value then I will develop it further.
